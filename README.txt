ARIKRISHNA PRAVEEN S - PERSONAL PORTFOLIO
==========================================

FILES
-----
index.html       Main website structure
style.css        Dark modern responsive design
script.js        Mobile menu, scroll reveal and current year
assets/          Add your profile photo and resume here

IMPORTANT PERSONAL CUSTOMIZATION
--------------------------------
1. Add your profile photo to assets and name it: profile.jpg
   Recommended: clear, professional portrait; square or 4:5 image.
2. Your uploaded resume is already included as assets/resume.pdf.
3. In index.html, replace every instance of:
      your.email@example.com
   with your actual professional email address.
4. GitHub and LinkedIn profile links have been added. Verify them before publishing.
5. Add actual GitHub repository links to the project cards if available.
6. Confirm the project descriptions and education details before publishing.

RUN IN VS CODE
--------------
1. Extract the ZIP file.
2. Open VS Code.
3. Select File > Open Folder and choose the arikrishna_portfolio folder.
4. Open index.html.
5. If Live Server is installed, right-click index.html and choose
   "Open with Live Server".
   Otherwise, double-click index.html in File Explorer to open it in a browser.

PUBLISH
-------
You can publish the static website using GitHub Pages or Netlify.
Before publishing, update the email, social links, photo and resume.
